# Values deltas — PodiumD 4.9.4 → 4.9.5

**No gemeente `podiumd.yml` changes are required for this hop** apart from the
Open Inwoner admin OIDC shape below. On SSCHostingSync `main` and
ExternalsPodiumD `main` (2026-10-17) every environment with Open Inwoner (78)
still has the old shape, so check every environment.

## openinwoner: admin OIDC must use the providers schema

Not new in 4.9.5. Since Open Inwoner 2.4.0
(PodiumD 4.8.4) `mozilla-django-oidc-db` 2.x only accepts
`oidc_db_config_admin_auth` with a separate `providers` list and an
`oidc_provider_identifier` per item. The 4.7 OIDC migration skipped
`openinwoner`, so environments can still have the old flat shape: `items`
with `endpoint_config`, `claim_mapping`, `username_claim`, `groups_claim`,
`superuser_group_names`, `make_users_staff` and `sync_groups` directly in the
item. The `openinwoner-config` job then fails, so the admin OIDC settings in
the values are not applied:

```text
oidc_db_config_admin_auth.items.0.oidc_provider_identifier
  String should match pattern ... [type=string_pattern_mismatch, input_value='']
```

An item that sets `oidc_provider_identifier` but keeps these flat fields
(without a `providers` list) passes validation only while the provider is
already in the database; its group settings are then written under
`group_settings`, which the admin plugin does not read, and the admin SSO
login fails with HTTP 500 (`KeyError: 'groups_settings'`).

Check and migrate with `charts/podiumd/scripts/migrate-openinwoner-admin-oidc.py`
from the 4.10.0 branch (#591); it only reads the values files, so it works for
a 4.9.5 environment too:

```bash
python3 charts/podiumd/scripts/migrate-openinwoner-admin-oidc.py --check --gemeenten-dir <SSCHostingSync>/applications/gemeenten
python3 charts/podiumd/scripts/migrate-openinwoner-admin-oidc.py --dry-run <gemeente>/<env>/podiumd.yml
```

Or rewrite the openinwoner block by hand as below (keep the environment's own
Keycloak URL, client id and secret):

```yaml
oidc_db_config_admin_auth:
  providers:
    - identifier: admin-oidc-provider
      endpoint_config:
        oidc_op_discovery_endpoint: "https://<keycloak>/realms/podiumd/"
  items:
    - identifier: admin-oidc
      enabled: true
      oidc_provider_identifier: admin-oidc-provider
      oidc_rp_scopes_list:
        - openid
        - email
        - profile
      userinfo_claims_source: id_token
      oidc_rp_client_id: openinwoner
      oidc_rp_client_secret: "<secret>"
      oidc_rp_sign_algo: RS256
      options:
        user_settings:
          claim_mappings:
            first_name:
              - given_name
            last_name:
              - family_name
            username:
              - preferred_username
        groups_settings:
          claim_mapping:
            - groups
          sync: true
          sync_pattern: "*"
          default_groups: []
          make_users_staff: true
          superuser_group_names:
            - administrators
```
