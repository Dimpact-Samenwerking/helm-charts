# Values deltas — PodiumD 4.9.4 → 4.9.5

No gemeente `podiumd.yml` changes are required for this hop. The post-deploy
steps (Open Formulieren logic conversion) are in
[`4.9.4-to-4.9.5-upgrade.md`](4.9.4-to-4.9.5-upgrade.md).

One pre-existing defect surfaces on this hop: an Open Inwoner
`oidc_db_config_admin_auth` block in the old flat shape (from before Open
Inwoner 2.4.0, PodiumD 4.8.4) makes the `openinwoner-config` job fail with an
empty `oidc_provider_identifier`, so the admin OIDC settings are not applied.
The 4.7 OIDC migration skipped `openinwoner`, so many environments still have
it. Check and migrate with
`charts/podiumd/scripts/migrate-openinwoner-admin-oidc.py` from `main`; it
only reads the values files and keeps the environment's own claim, group,
PKCE and nonce settings. Details and the resulting block:
[`4.9.5-to-4.10.0-upgrade.md`](4.9.5-to-4.10.0-upgrade.md#reference-open-inwoner-admin-oidc-the-providers-schema).
