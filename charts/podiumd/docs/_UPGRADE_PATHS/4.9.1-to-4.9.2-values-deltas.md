## Namespace portability

No `podiumd.yml` changes are required for deployments in the `podiumd` namespace.

If you deploy into a **different** namespace, set the three operator watch-scopes to that
namespace (they cannot be templated in `values.yaml`):

```yaml
eck-operator:
  managedNamespaces:
    - <namespace>
zac:
  solr-operator:
    watchNamespaces: "<namespace>"
    zookeeper-operator:
      watchNamespace: "<namespace>"
```

See `charts/podiumd/ci/values-namespace-scope.example.yaml` and
`docs/misc/deploying-to-a-custom-namespace.md`. All other cluster-internal references (Redis,
`allowedHosts`, ClamAV, Kibana) now follow the release namespace automatically.
