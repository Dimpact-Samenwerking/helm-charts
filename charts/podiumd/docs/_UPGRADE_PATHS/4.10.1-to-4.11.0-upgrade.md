# Upgrade guide: PodiumD 4.10.1 → 4.11.0

> See the Confluence Releases page for the agreed application
> targets: <https://dimpact.atlassian.net/wiki/spaces/PCP/pages/7602191/Releases+PodiumD>.

For environments already on **4.10.1**. The guide has three parts:

1. **The runbook** (sections A to F): what to run, in which order, and what
   to check. Written for the deploy pipeline.
2. **Component versions and changes**: the record of what moved in the chart.
3. **Reference**: the detail per topic, for when a step fails or a choice has
   to be made.

## E. After the deploy

### E1. Open Klant: smoke test the clients

Open Klant 2.16.0 no longer generates `nummer` for a klantcontact, an
interne taak or a partij; a client that shows it gets an empty field. After
`helm upgrade`, per environment:

- KISS: register a contactmoment and open it again; create a contactverzoek.
- ITA: open a new interne taak.

Both only read and write test data; repeat them as often as needed. Background:
[Reference: Open Klant 2.19](#reference-open-klant-219).

## Changes that need no action

- **Open Klant's Celery result backend is set** (Redis db 8): chart 1.14.2
  reads `settings.celery.resultBackend` instead of the misspelled
  `resultBackendl`, which podiumd now uses. Before, it was empty.
- **Open Klant's configuration job is a Helm hook** (chart 1.14.2), deleted
  before the next run; `configuration.job.ttlSecondsAfterFinished` is gone.
- **Open Klant chart 1.14.2 turns Flower on by default**; podiumd keeps it off.
- **Open Klant logs every API request** (`LOG_REQUESTS` is `True` since
  2.17.0) and no longer stores outgoing request bodies.

## Changes

### openklant 2.15.0 → 2.19.2 (chart 1.11.0 → 1.14.2)

Chart 1.14.2 is the newest; it is built for Open Klant 2.18.1, and no chart
for 2.19 exists yet. After the deploy:
[E1](#e1-open-klant-smoke-test-the-clients). Background:
[Reference: Open Klant 2.19](#reference-open-klant-219).

PodiumD 4.11.0 upgrades **openklant** from app version 2.15.0
to 2.19.2.

- Helm chart `openklant` `1.11.0` → `1.14.2` in
  `charts/podiumd/Chart.yaml`.
- Image tag pin `openklant.image.tag` `2.15.0` → `2.19.2` in
  `charts/podiumd/values.yaml`.

- Image / digest: see [`images-4.11.0.yaml`](../images/images-4.11.0.yaml).

## Reference: Open Klant 2.19

- **No `nummer` (2.16.0):** `InterneTaak.nummer`, `Klantcontact.nummer` and
  `Partij.nummer` are deprecated and no longer generated. New
  `referentienummer` fields on interne taak and klantcontact hold a client's
  own reference.
- **Image and chart (2.19.2 on chart 1.14.2):** the chart is built for 2.18.1.
  The 2.19 releases add no setting or environment variable; 2.19.0's migration
  crashes and is fixed in 2.19.1.
- **`UWSGI_PORT` is now `OPENKLANT_PORT` (2.18.0):** Kubernetes would inject
  `OPENKLANT_PORT=tcp://<ip>:80` for the `openklant` Service, as for Open Zaak
  (open-zaak#2415); chart 1.14.2 sets `enableServiceLinks: false` on the web
  pod, so nothing is injected.
- **Optional cleanup (2.19.0):** the temporary management command
  `delete_klantcontacten_not_related_to_zaken` deletes klantcontacten without
  a zaak. Run it only on request of the gemeente.
