# Values deltas — PodiumD 4.10.0 → 4.10.1

What changes in a gemeente `podiumd.yml`, `services-gateway.yml` and
`ssl-gateway.yml` for this hop, and nothing else. Why, the pre- and
post-deploy steps and the rollback are in
[`4.10.0-to-4.10.1-upgrade.md`](4.10.0-to-4.10.1-upgrade.md); findings per
environment in
[`4.10.0-to-4.10.1-gemeente-specific.md`](4.10.0-to-4.10.1-gemeente-specific.md).
No component section: the only component that moves, Open Formulieren, is a
version bump. `services-gateway.yml` and `ssl-gateway.yml` do not change.

The changes marked *script* are made by `charts/podiumd/scripts` of the
4.10.1 chart:

```bash
pip install ruamel.yaml
G=<SSCHostingSync>/applications/gemeenten
python3 charts/podiumd/scripts/migrate-objecten-openarchiefbeheer-permissions-4.10.1.py --gemeenten-dir "$G"  # objecten tokenauth
python3 charts/podiumd/scripts/migrate-objecten-kiss-logboek-permission-4.10.1.py --gemeenten-dir "$G"        # objecten tokenauth
```

`objecten.configuration.data`, *script*: the `tokenauth` items of Open
Archiefbeheer and of KISS's logboek token.

```yaml
tokenauth:
  items:
    - identifier: openarchiefbeheer
      # ...
      permissions:                                        # new, when the item had none
        - object_type: "REP_ZAC_PRODUCTAANVRAAG_UUID_REP"
          mode: read_and_write
    - identifier: contact                                 # the item whose token is kiss.settings.logboek.token
      # ...
      permissions:
        # ... its existing permissions
        - object_type: "REP_ITA_ACTIVITEITENLOG_UUID_REP"  # new
          mode: read_only
```

By hand, only in environments with an ACR and ZAC:

```yaml
zac:
  restartAfterOpenzaakConfig:
    image:
      repository: <acr>/alpine/k8s                        # new
```

By hand, only where `keycloak.podTemplate.spec.containers` is overridden:

```yaml
keycloak:
  podTemplate:
    spec:
      containers:
        - name: keycloak
          volumeMounts:
            - name: keycloak-build-data                   # remove every mount of this volume
```
