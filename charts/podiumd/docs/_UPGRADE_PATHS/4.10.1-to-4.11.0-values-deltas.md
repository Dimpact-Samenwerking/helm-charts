## zac 5.9.1 → 5.12.0 (chart 1.0.355 → 1.0.385)

Only where ZAC sends its traces to the monitoring collector through
`zac.opentelemetry_zaakafhandelcomponent.endpoint` (ExternalsPodiumD
`09a9d10`: 6 of 8 environments, the `ontw` environments of dim2, dim3, dimp,
icat, info and mayk):

```yaml
zac:
  tracing:
    enabled: true                                   # new
    endpoint: "http://monitoring-opentelemetry-collector.monitoring.svc.cluster.local:4317"   # was opentelemetry_zaakafhandelcomponent.endpoint
  opentelemetry_zaakafhandelcomponent:              # remove
  opentelemetry-collector:                          # remove; enabled with replicaCount 0, it only turned tracing on
```

Recommended, not yet required: chart 1.0.385 still reads the old keys and
prints a deprecation notice for each; a later chart drops them.
