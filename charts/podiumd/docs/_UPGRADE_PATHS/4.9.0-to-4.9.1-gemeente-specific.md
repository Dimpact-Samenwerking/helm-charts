# Gemeente-specific notes — PodiumD 4.9.0 → 4.9.1

Findings for this hop that apply to a **specific gemeente or environment** —
not to the release in general — are collected here: data quirks, local
overrides, hosting particulars, incident follow-ups.

## Assen

The MI-data export's `ftp` transfer mode uploads via `curl`, which defaults
to EPSV (RFC 2428) for the data connection. Assen's FTP server/path can't
handle EPSV — the control connection succeeds but the data connection then
hangs/resets. mi-data chart 1.1.0 ([IN-2812](https://dimpact.atlassian.net/browse/IN-2812))
adds `mi.transfer.noEpsv`, which forces classic PASV (`curl --no-epsv`).
Set it for Assen's `mi.transfer` block:

```yaml
mi:
  transfer:
    noEpsv: true
```

See [`charts/mi-data/docs/mi-exports.md`](../../../mi-data/docs/mi-exports.md)
for the full option reference.
