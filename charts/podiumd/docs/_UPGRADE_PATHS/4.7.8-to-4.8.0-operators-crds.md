# Operators & CRDs — PodiumD 4.7.8 → 4.8.0

Companion to [`4.7.8-to-4.8.0-upgrade.md`](4.7.8-to-4.8.0-upgrade.md).

| Component | Change | CRD impact | Action |
|---|---|---|---|
| eck-operator | **Introduced** as central root-level dependency (`3.4.0`, replacing the kisselastic-era operator) + `eck-stack` `0.19.0` (alias `kiss-eck`) | **12 ECK CRDs** required. 4.8.0 - 4.8.3: installed by the chart (`installCRDs: true`). **4.8.4+: out-of-band** (`installCRDs: false`) | Target 4.8.4+: run `install-eck-operator-crds.sh` before the deploy. | keycloak-operator | Unchanged (server + operator `26.6.3`, adfinis `1.12.0`) | None | None |

## ECK CRDs: before the deploy

### Target 4.8.4 or later (recommended)

The chart no longer renders the CRDs. Rendering them adds ~775 KB to the
manifest, and helm stores every revision as one Kubernetes Secret capped at
1 MiB, so on grown environments the deploy fails before it applies anything:
`Secret "sh.helm.release.v1.podiumd.v<n>" is invalid: data: Too long`.

Apply the CRDs out-of-band instead (cluster-admin, idempotent, `--dry-run` to
preview). Repeat on every `eck-operator` version bump:

```bash
charts/podiumd/scripts/install-eck-operator-crds.sh --context <kubectl-context>
```

No ownership adoption needed, because helm never touches the CRDs. Still run
`pre-upgrade-prep-4.8.0.sh` for the RabbitMQ drain check and the Elasticsearch
baseline.

### Target 4.8.0 - 4.8.3

Those releases install the CRDs through the chart. On clusters where the ECK
CRDs already exist without `podiumd` release ownership (kisselastic era), Helm
refuses to upgrade them (`invalid ownership metadata`). The helper script
adopts the CRDs, checks the RabbitMQ drain and records the Elasticsearch
baseline in one go:

```bash
charts/podiumd/scripts/pre-upgrade-prep-4.8.0.sh --context <kubectl-context>
```

Deploying with **stale** CRDs crashloops the operator. If the deploy hits the
1 MiB Secret error, switch to the 4.8.4 approach: set
`eck-operator.installCRDs: false` in the environment values and run
`install-eck-operator-crds.sh`.
