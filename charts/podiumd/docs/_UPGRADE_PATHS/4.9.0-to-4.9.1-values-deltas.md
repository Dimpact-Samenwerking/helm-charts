### Notes

**[1] The Keycloak digest moves out of `tag` into a sibling `sha`.** Only
environments that pin Keycloak themselves are affected — none do today. Leaving
the digest in `tag` renders a double digest and the pod never starts; see
[the upgrade guide](4.9.0-to-4.9.1-upgrade.md#breaking--keycloak-image-pinning-moved-to-a-split-tagsha).

```yaml
keycloak:
  image:
    tag: "26.7.3"
    sha: "ff4257d0d64efbe99ed1ddfaf07765cc3c36dc7518bf8324d41961327f441c54"
```

**[2]** `mi.transfer.mode: ftp` only, and only where the FTP server rejects
EPSV — Assen today, see
[gemeente-specific](4.9.0-to-4.9.1-gemeente-specific.md).

**[3] Seeding replaces all PABC content.** Enable only on an environment whose
PABC database is empty; on one curated through the PABC UI, leave both `false`.
`seedJob` requires `datasetConfigMap`. See
[`enabling-pabc.md`](../apps/pabc/enabling-pabc.md).
