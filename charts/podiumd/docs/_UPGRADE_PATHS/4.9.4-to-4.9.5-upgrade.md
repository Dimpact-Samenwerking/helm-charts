# Upgrade guide: PodiumD 4.9.4 → 4.9.5

> See the Confluence Releases page for the agreed application
> targets: <https://dimpact.atlassian.net/wiki/spaces/PCP/pages/7602191/Releases+PodiumD>.

This is the upgrade guide for environments already on **4.9.4**.

PodiumD 4.9.5 brings Open Inwoner 2.4.7, a security fix for the editor used by
administrators and editors.

## Before you deploy (every environment)

- **Mirror the new image.** `maykinmedia/open-inwoner` 2.4.7 must be in the
  registry the environment pulls from; it is listed in
  [`images-4.9.5.yaml`](../images/images-4.9.5.yaml).

## Component versions (4.9.5 vs 4.9.4)

| Component | App version | Helm chart | Notes |
| --- | --- | --- | --- |
| openinwoner | 2.4.6 → 2.4.7 | 2.4.0 (unchanged) | security fix (CMS editor XSS) |

## Changes

### openinwoner 2.4.6 → 2.4.7 (chart 2.4.0, unchanged)

PodiumD 4.9.5 upgrades **openinwoner** from app version 2.4.6 to 2.4.7. This
is an image bump only; no chart, values or database changes.

- Image tag pin `openinwoner.image.tag` `2.4.6` → `2.4.7` in
  `charts/podiumd/values.yaml`.
- Image / digest: see [`images-4.9.5.yaml`](../images/images-4.9.5.yaml).

Release notes:
[2.4.7](https://github.com/maykinmedia/open-inwoner/blob/v2.4.7/CHANGELOG.rst).

- **Security:** `maykin-django-prosemirror` 0.12.0 fixes GHSA-c8x8-7fp4-3x9w
  (CVE-2026-104847): pasting malicious HTML into the ProseMirror editor could
  run JavaScript in the browser. Only administrators and editors are at risk
  (the editor is used in the admin and the CMS). Maykin advises upgrading
  soon.
- **Bug fixes:** the plugin picker in the CMS structure view lists all
  plugins a placeholder allows again (#3059); apphook pages ("Samenwerken",
  "Mijn profiel") can be switched to structure mode and published again
  (#3075); creating a page with the CMS wizard no longer fails with a
  `TypeError` (#3088, `django-formtools` update).
