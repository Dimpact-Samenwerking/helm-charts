## Open Archiefbeheer logs to stdout (IN-3284)

- **Application logs move from a file to stdout.** The podiumd chart now sets
  `openarchiefbeheer.settings.logging.toStdout: true` (with `level: INFO`).
  The openarchiefbeheer chart writes `LOG_STDOUT=False` unless this is set,
  so OAB logged to a file in the container, which Grafana does not collect.
  After the upgrade the OAB logs, such as destruction list processing and
  OIDC login errors, show in Grafana.
- **Celery worker and beat log at `info` instead of `warning`.**
  `openarchiefbeheer.settings.celery.logLevel` goes from `warning` to `info`.
  On `warning` beat logs only its startup banner and the worker a few lines
  a day, so they hardly showed in the Grafana Logs dashboard.
- **More log volume in Loki.** Both changes increase the number of OAB log
  lines.
- An environment that sets `openarchiefbeheer.settings.logging` or
  `openarchiefbeheer.settings.celery.logLevel` in its `podiumd.yml` keeps its
  own value. No SSC environment sets them today.
