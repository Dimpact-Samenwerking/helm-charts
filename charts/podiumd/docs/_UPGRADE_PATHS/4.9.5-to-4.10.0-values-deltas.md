# Values deltas — PodiumD 4.9.5 → 4.10.0

What changes in a gemeente `podiumd.yml`, `services-gateway.yml` and
`ssl-gateway.yml` for this hop, and nothing else. Why, the pre- and
post-deploy steps and the rollback are in
[`4.9.5-to-4.10.0-upgrade.md`](4.9.5-to-4.10.0-upgrade.md); findings per
environment in
[`4.9.5-to-4.10.0-gemeente-specific.md`](4.9.5-to-4.10.0-gemeente-specific.md).
Counts: SSCHostingSync `36f44d2` (78 environments, 8 of them stubs deployed
from ExternalsPodiumD) and ExternalsPodiumD `aedfa87` (8 environments).

## Scripts

The changes marked *script* below are made by `charts/podiumd/scripts` of the
4.10.0 chart. Each script keeps comments, quoting and `REP_..._REP`
placeholders, shows a unified diff with `--dry-run`, and changes nothing on a
second run:

```bash
pip install ruamel.yaml
G=<SSCHostingSync>/applications/gemeenten
python3 charts/podiumd/scripts/migrate-objecten-4.1.0.py --gemeenten-dir "$G"               # objecten: podiumd.yml and services-gateway.yml
python3 charts/podiumd/scripts/migrate-openforms-4.0-api-groups.py --gemeenten-dir "$G"     # openformulieren
python3 charts/podiumd/scripts/migrate-openinwoner-admin-oidc.py --gemeenten-dir "$G"       # openinwoner
python3 charts/podiumd/scripts/migrate-zookeeper-hooks-image-4.10.0.py --gemeenten-dir "$G" # zac
python3 charts/podiumd/scripts/migrate-eck-resources-4.10.0.py --gemeenten-dir "$G"         # kiss-eck
python3 charts/podiumd/scripts/migrate-gateway-security-headers.py --gemeenten-dir "$G"     # ssl-gateway.yml
```

## `ssl-gateway.yml`

Every environment with ZAC, one policy per route (`hr-zac-nginx`, and
`hr-openzaak-nginx` with its own `metadata.name`; the unit must be lowercase):

```yaml
apiVersion: gateway.nginx.org/v1alpha1
kind: ClientSettingsPolicy
metadata:
  name: zac-large-documents                         # e.g. openzaak-large-documents for the second one
  namespace: ingress-basic
spec:
  targetRef:
    group: gateway.networking.k8s.io
    kind: HTTPRoute
    name: hr-zac-nginx
  body:
    maxSize: "600m"
```

Every environment, every HTTPRoute rule with `backendRefs` (IN-3162; *script:*
`migrate-gateway-security-headers.py`, which SSC runs in its own hosting
repo):

```yaml
filters:
  - type: ResponseHeaderModifier
    responseHeaderModifier:
      set:
        - name: Strict-Transport-Security
          value: max-age=31536000
        - name: X-Content-Type-Options
          value: nosniff
```
