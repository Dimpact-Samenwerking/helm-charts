## Changes

### nginx-unprivileged 1.31.6 → 1.31.9

PodiumD 4.9.7 upgrades the shared **nginx-unprivileged** image to 1.31.9,
pinned at:

- `global.images.nginx.tag` `1.31.6` → `1.31.9`
- `openzaak.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)
- `openarchiefbeheer.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)
- `openklant.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)
- `openformulieren.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)
- `openinwoner.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)
- `openbeheer.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)
- `zac.nginx.image.tag` `1.31.6` → `1.31.9` (shares a YAML anchor with `global.images.nginx.tag`)

- Image / digest: see [`images-4.9.7.yaml`](../images/images-4.9.7.yaml).

nginx 1.31.7 and 1.31.9 are security releases. 1.31.7 fixes
CVE-2026-15176, CVE-2026-93479, CVE-2026-95101, CVE-2026-97629 and
CVE-2026-97205; 1.31.9 fixes CVE-2026-125283, CVE-2026-123007,
CVE-2026-123633, CVE-2026-121810, CVE-2026-123634, CVE-2026-113425,
CVE-2026-120967, CVE-2026-120993, CVE-2026-123640 and CVE-2026-118899. See
the [nginx changelog](https://nginx.org/en/CHANGES).

The repository moves from `nginxinc/nginx-unprivileged` to
`nginx/nginx-unprivileged` (`global.images.nginx.repository`, shared by all
the paths above). Docker Hub archived the `nginxinc` repository; its last
release is 1.31.7. The new repository builds the same image (port 8080, PID
file in `/tmp`, uid 101), but with its own digests. An environment that pulls
through a mirror must mirror `docker.io/nginx/nginx-unprivileged` 1.31.9 by
digest before the deploy: a mirror that still syncs from
`docker.io/nginxinc/nginx-unprivileged` fails to pull on every nginx
sidecar, the API proxy and the Frank!Gateway dashboard shim.
