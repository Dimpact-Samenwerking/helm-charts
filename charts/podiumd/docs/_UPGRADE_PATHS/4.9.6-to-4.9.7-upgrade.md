### nginx-unprivileged 1.31.6 → 1.31.7

pinned at:

- `global.images.nginx.tag` `1.31.6` → `1.31.7`
- `openzaak.nginx.image.tag` `1.31.6` → `1.31.7` (shares a YAML anchor with `global.images.nginx.tag`)
- `openarchiefbeheer.nginx.image.tag` `1.31.6` → `1.31.7` (shares a YAML anchor with `global.images.nginx.tag`)
- `openklant.nginx.image.tag` `1.31.6` → `1.31.7` (shares a YAML anchor with `global.images.nginx.tag`)
- `openformulieren.nginx.image.tag` `1.31.6` → `1.31.7` (shares a YAML anchor with `global.images.nginx.tag`)
- `openinwoner.nginx.image.tag` `1.31.6` → `1.31.7` (shares a YAML anchor with `global.images.nginx.tag`)

- `zac.nginx.image.tag` `1.31.6` → `1.31.7` (shares a YAML anchor with `global.images.nginx.tag`)

- Image / digest: see [`images-4.9.7.yaml`](../images/images-4.9.7.yaml).

nginx 1.31.7 is a security release. It fixes CVE-2026-15176 (`alias` after
`rewrite`), CVE-2026-93479 (string expressions with variables),
CVE-2026-95101 (HTTP/3 unknown frames), CVE-2026-97629 (TLS session ticket
key rotation) and CVE-2026-97205 (AIO with SSI `include virtual`). No
configuration change is needed: the PodiumD nginx configs keep working
as-is. See the [nginx changelog](https://nginx.org/en/CHANGES).
