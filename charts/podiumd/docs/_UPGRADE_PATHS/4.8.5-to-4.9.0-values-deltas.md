# Values deltas — PodiumD 4.8.5 → 4.9.0

**No gemeente `podiumd.yml` changes are required for this hop.**

Both changes ship entirely in the chart `values.yaml` defaults:

- **ZAC** app `5.0.2 → 5.4.3` (chart `1.0.297`, unchanged) — image tag only
  (plus the OPA sidecar `openpolicyagent/opa` `1.17.1-static → 1.19.0-static`).
- **ZGW Office Add-in** frontend + backend `v0.9.313 → 0.11.0` (chart
  `0.0.89` → `0.0.92`) — image tags only.

Every environment checked overrides `registry`/`repository` for these images
(their own ACR mirror) but never `tag`, so the new tags/digests apply from the
chart defaults automatically.

The only prerequisite is mirroring the new ZAC `5.4.3` and ZGW Office Add-in
`0.11.0` digests — already listed in
[`images-4.9.0.yaml`](../images/images-4.9.0.yaml).
