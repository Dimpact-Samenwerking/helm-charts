# Upgrade guide: PodiumD 4.7.7 → 4.7.8

4.7.8 is a small patch release: it adds a startup workaround for **Open Zaak**
1.27.3. No images change.

## Changes

### Open Zaak — pin `OPENZAAK_PORT` (uwsgi startup failure)

Since Open Zaak 1.27.3 the application reads the `OPENZAAK_PORT` environment
variable as the uwsgi port number. Kubernetes service discovery auto-injects
`OPENZAAK_PORT=tcp://<svc-ip>:80` for the `openzaak` Service, which uwsgi
cannot parse — Open Zaak pods fail to start. See
[open-zaak/open-zaak#2415](https://github.com/open-zaak/open-zaak/issues/2415).

The chart now pins the variable explicitly in `charts/podiumd/values.yaml`:

```yaml
openzaak:
  extraEnvVars:
    - name: OPENZAAK_PORT
      value: "8000"
```

#### Action required

- **None for standard environments** — the fix ships in the chart defaults.
- If your gemeente `podiumd.yml` overrides `openzaak.extraEnvVars`, that
  override **replaces** the chart default list — include the `OPENZAAK_PORT`
  entry in your own list.
- No image, config, schema, or migration changes; nothing to mirror.
