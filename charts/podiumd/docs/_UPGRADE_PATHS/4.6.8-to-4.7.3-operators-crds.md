# Operators & CRDs — PodiumD 4.6.8 → 4.7.3

Companion to [`4.6.8-to-4.7.3-upgrade.md`](4.6.8-to-4.7.3-upgrade.md).

| Component | Change | CRD impact | Action |
|---|---|---|---|
| keycloak-operator | Operator image → `26.6.x` while the adfinis subchart stays `1.11.4` (bundles `26.5.6`-era CRDs) | **`k8s.keycloak.org` CRDs must move `v2alpha1` → `v2beta1`** — the 26.6.x operator queries `v2beta1` and `CrashLoopBackOff`s without it | Run `install-keycloak-operator-crds.sh` **before** the deploy, then restart the operator |

## Keycloak CRD upgrade (`v2alpha1` → `v2beta1`)

```bash
# 1. Inspect what would be applied
charts/podiumd/scripts/install-keycloak-operator-crds.sh --dry-run

# 2. Install upstream CRDs (adds v2beta1, keeps v2alpha1 deprecated/served)
charts/podiumd/scripts/install-keycloak-operator-crds.sh \
  --context "$CTX"

# 3. Restart the operator so it re-establishes informers
kubectl --context "$CTX" -n "$NS" rollout restart deploy keycloak-operator
```

The script accepts `--keycloak-version` to pin a specific release and
`--source chart --chart-version 1.11.4` to fall back to the adfinis subchart
CRDs. Background and verification steps:
[upgrade guide § Keycloak CRD upgrade](4.6.8-to-4.7.3-upgrade.md#keycloak-crd-upgrade-v2alpha1--v2beta1).
