# Operators & CRDs — PodiumD 4.6.0 → 4.6.4

Companion to [`4.6.0-to-4.6.4-upgrade.md`](4.6.0-to-4.6.4-upgrade.md)
(reference route — the official path enters 4.6.4 via 4.5.16).

| Component | Change | CRD impact | Action |
|---|---|---|---|
| redis-operator | Redis HA PVCs move to `managed-csi-premiumv2` | **`RedisReplication` CRD updated** by `helm upgrade` | Delete the Redis HA StatefulSet first so the operator recreates it with the new `volumeClaimTemplate` — sequence in the guide |
| keycloak-operator | `ensure-keycloak-operator-sa` job | None | Set the SA client secret / pipeline replacement (as on the 4.5.16 route) |

## Order of operations (redis)

1. Delete the Redis HA StatefulSet (operator-managed — it is recreated).
2. `helm upgrade` — this updates the `RedisReplication` CRD.
3. Verify the recreated StatefulSet shows `managed-csi-premiumv2`; if it still
   shows `managed-csi`, the operator has not reconciled yet — wait and recheck.

Full commands: see the [upgrade guide](4.6.0-to-4.6.4-upgrade.md).
