# Upgrade guide: PodiumD 4.8.0 → 4.8.1

PodiumD 4.8.1 only Adds `charts/podiumd/.helmignore` so the packaged chart stays lean:

- `docs/ — operator documentation` (~1.2M) lives in git/GitHub, not in the deployed chart. It pushed the helm release Secret over the Kubernetes 1MiB cap.
- `ci/` — CI-only lint values.
- Editor/VCS junk (`.DS_Store`, `*.swp`, etc.).
- `scripts/` — one-off operational scripts live in git, not in the packaged chart 

This keeps the package under the 1MiB helm release Secret cap.

No substantive changes to the chart.
