# Values deltas — PodiumD 4.7.7 → 4.7.8

No gemeente `podiumd.yml` changes are required for this hop — the
`OPENZAAK_PORT` workaround ships in the chart `values.yaml` defaults.

Only exception: a gemeente file that overrides `openzaak.extraEnvVars`
replaces the chart default list and must include the `OPENZAAK_PORT` entry —
see the upgrade guide:
