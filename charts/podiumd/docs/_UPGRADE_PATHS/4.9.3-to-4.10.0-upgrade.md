## Changes

### Keycloak: default client scopes on every client

No action required. The realm config now sets `defaultClientScopes` on every
client in the `podiumd` realm: `web-origins`, `acr`, `profile`, `roles`,
`basic` and `email`, plus `service_account` for service-account clients.

Since 4.9.1 the clients only had `optionalClientScopes`, and Keycloak then
creates a client without any default scopes. Environments whose realm was
created on 4.9.1 or later therefore issue tokens without `realm_access`,
`resource_access`, `sub`, profile and email claims (ZAC: `functional roles:
'[]'` and a 403). The realm import of this release adds the missing scopes to
the existing clients. Environments whose clients predate 4.9.1 already have
these scopes and see no change. See
[keycloak-default-client-scopes.md](../apps/keycloak/keycloak-default-client-scopes.md).
