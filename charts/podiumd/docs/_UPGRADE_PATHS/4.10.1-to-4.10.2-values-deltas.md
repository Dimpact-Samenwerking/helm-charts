## redis-operator - redis v8.10.1 → 8.10.3-alpine

Every environment that overrides the redis-ha image with an ACR mirror
(`scripts/migrate-redis-ha-image-4.10.2.py` makes this change):

```yaml
redis-operator:
  redis-ha:
    image:
      registry: acrprodmgmt.azurecr.io   # acrtestmgmt.azurecr.io for gene ontw
      repository: library/redis          # was opstree/redis
```
