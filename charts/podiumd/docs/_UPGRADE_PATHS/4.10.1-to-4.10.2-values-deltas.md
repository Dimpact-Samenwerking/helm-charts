# Values deltas — PodiumD 4.10.1 → 4.10.2

What changes in a gemeente `podiumd.yml`, `services-gateway.yml` and
`ssl-gateway.yml` for this hop, and nothing else. Why, the pre- and
post-deploy steps and the rollback are in
[`4.10.1-to-4.10.2-upgrade.md`](4.10.1-to-4.10.2-upgrade.md).

None for most environments. The nginx-unprivileged repository moves in the
chart; a gemeente `repository:` override of a mirror keeps working once the
mirror holds 1.31.9 from `nginx/nginx-unprivileged` (upgrade guide, C1).

Only where `openformulieren.customerInteractionsConfigJob.enabled` is `true`
and setup-configuration runs: `openformulieren.configuration.data` needs the
Open Klant service the Job points at, or the render fails (upgrade guide, B1):

```yaml
openformulieren:
  configuration:
    data: |
      zgw_consumers_config_enable: true
      zgw_consumers:
        services:
          - identifier: openklant-api   # = customerInteractionsConfigJob.serviceIdentifier
            label: Open Klant klantinteracties
            api_root: https://openklant.<domain>/klantinteracties/api/v1/
            api_type: kc
            auth_type: api_key
            header_key: Authorization
            header_value: Token REP_OPENKLANT_OPENFORMULIEREN_TOKEN_REP
```
