# Values deltas — PodiumD 4.8.1 → 4.8.2

No gemeente `podiumd.yml` changes are required for this hop — the update needed for the
objecten subchart bump (2.12.0 → 2.12.1) ships in the chart `values.yaml` defaults.

The `nginx-unprivileged` (1.31.1 → 1.31.3), `curl` (8.20.0 → 8.21.0) and `busybox`
consolidation (see [`4.8.1-to-4.8.2-upgrade.md`](4.8.1-to-4.8.2-upgrade.md)) also
needs no gemeente edit — every environment checked overrides `registry`/`repository`
for these images but never `tag`, so the new tags/digests apply from the chart
defaults automatically. The only prerequisite is mirroring the new
`nginx-unprivileged:1.31.3` and `curlimages/curl:8.21.0` digests, already listed in
[`images-4.8.2.yaml`](../images/images-4.8.2.yaml).
