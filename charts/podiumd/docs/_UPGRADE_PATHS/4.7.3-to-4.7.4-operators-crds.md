## Digest-pin caveat — `operator.image.sha`

The operator image is the **only** image whose digest is pinned via a separate
field: the adfinis subchart renders `repository:tag@sha256:{{ operator.image.sha }}`.
The chart default `sha` pins the upstream 26.6.3 digest. On environments where
the mirrored digest differs (e.g. aks-blue / ACR mirrors), **disable** the pin:

```yaml
keycloak-operator:
  operator:
    image:
      sha: ""
```

Details: [upgrade guide](4.7.3-to-4.7.4-upgrade.md).
