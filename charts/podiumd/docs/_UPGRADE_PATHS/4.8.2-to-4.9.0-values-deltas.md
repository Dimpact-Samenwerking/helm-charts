Both changes ship entirely in the chart `values.yaml` defaults:

- **ZAC** app `5.0.1 → 5.3.0` (chart `1.0.251 → 1.0.281`) — image tag only
  (plus the OPA sidecar `openpolicyagent/opa` `1.17.1-static → 1.18.2-static`).
- **ZGW Office Add-in** frontend + backend `v0.9.313 → 0.10.0` (chart
  `0.0.89`, unchanged) — image tags only.

Every environment checked overrides `registry`/`repository` for these images
(their own ACR mirror) but never `tag`, so the new tags/digests apply from the
chart defaults automatically.

The only prerequisite is mirroring the new ZAC `5.3.0` and ZGW Office Add-in
`0.10.0` digests — already listed in
[`images-4.9.0.yaml`](../images/images-4.9.0.yaml).
