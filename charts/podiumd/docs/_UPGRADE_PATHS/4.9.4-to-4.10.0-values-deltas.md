## openformulieren 3.5.8 (chart 1.12.0, unchanged)

- Key `openformulieren.settings.cookieSamesite` was added.

It is set to `Strict`. The chart turns it into `SESSION_COOKIE_SAMESITE`,
`CSRF_COOKIE_SAMESITE` and `LANGUAGE_COOKIE_SAMESITE`; before 4.10.0 these
were unset (Django's default `Lax`).

With `Strict` the browser leaves these cookies off every cross-site request:
the return from DigiD or eHerkenning, links to a form from another site and
forms embedded on a gemeente website. Test login and any embed on test or
accp first. An environment where that breaks sets `Lax` in its own values:

```yaml
openformulieren:
  settings:
    cookieSamesite: Lax
```

No SSC environment set it at SSCHostingSync `539b0c1` (2026-10-07).
