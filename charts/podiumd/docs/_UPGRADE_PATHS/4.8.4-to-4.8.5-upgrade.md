# Upgrade guide: PodiumD 4.8.4 → 4.8.5

> See the Confluence Releases page for the agreed application
> targets: <https://dimpact.atlassian.net/wiki/spaces/PCP/pages/7602191/Releases+PodiumD>.

This is the upgrade guide for environments already on **4.8.4**.

## Changes

### Open Beheer `0.9.0` → `0.9.1`

4.8.5 bumps the **Open Beheer** application image from `0.9.0` to `0.9.1`. The
`openbeheer` Helm chart stays at `0.1.3`.

0.9.1 brings improved session management, UI experience, branding, and stability.
Highlights relevant for operators:

- **`SESSION_EXPIRE_AT_BROWSER_CLOSE`** — new env var allowing sessions to end on
  browser close. Not yet exposed as a named `settings.*` values key in chart `0.1.3`.
  The application default is `False` (sessions persist until `SESSION_COOKIE_AGE`
  expires, unchanged from 0.9.0).
- **`SESSION_COOKIE_AGE`** — already configurable via `openbeheer.settings.sessionCookieAge`;
  no change.
- CSP fix: selectielijstklasse results now fetched via BFF instead of direct browser call.
- Broken breadcrumbs fix.
- Automatic redirect to the login page when a user's session expires.
- Updated branding and logo.

The uWSGI `--master` workaround (`settings.uwsgi.master: "1"`) **remains required** —
0.9.1 does not fix the upstream image. See
[openbeheer-known-issues.md](../apps/openbeheer/openbeheer-known-issues.md).

#### Action required

- No config, schema, or migration changes.
- Image / digest: see [`docs/images/images-4.8.5.yaml`](../images/images-4.8.5.yaml).
