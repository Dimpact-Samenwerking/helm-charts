# Gemeente-specific notes — PodiumD 4.8.2 → 4.8.3

Findings for this hop that apply to a **specific gemeente or environment** —
not to the release in general — are collected here: data quirks, local
overrides, hosting particulars, incident follow-ups.

## jim00 (QA)

- jim00 validated the new **ftp transfer mode** end-to-end (IN-2499): gemeente
  name `rotjeknor`, upload to a throwaway vsftpd server on Azure Container
  Instances (`rg-mi-ftp-test-jim00`). That test server is **temporary** — once
  it is torn down the weekly `mi-export-*` jobs on jim00 will fail at the
  upload step until `mi.transfer` is repointed (or `mi.enabled` set to
  `false`).
- The Key Vault secret `mi-data-sftp-credential-jim00` currently holds the FTP
  test password; earlier versions (rotjeknor SSH key, floepdorp SFTP password)
  remain recoverable in the secret's version history.
