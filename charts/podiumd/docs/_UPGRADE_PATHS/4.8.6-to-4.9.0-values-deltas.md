# Values deltas — PodiumD 4.8.6 → 4.9.0

**Identical to the 4.8.5 → 4.9.0 hop** — see
[`4.8.5-to-4.9.0-values-deltas.md`](4.8.5-to-4.9.0-values-deltas.md) for the
full key-by-key gemeente `podiumd.yml` reference (KISS 3.0.0 and ITA 3.3.0 are
the entries that require edits).

4.8.6 added no gemeente-facing keys of its own — its only values change was
podiumd's chart-default `keycloak-operator.operator.image.sha` override, which
4.9.0 drops along with the operator downgrade. If (and only if) an environment
copied that override into its own `podiumd.yml`, **remove it** before upgrading:
a 26.7.2 operator digest pinned onto 4.9.0's `26.6.4` tag renders an unpullable
image reference. See
[`4.8.6-to-4.9.0-upgrade.md`](4.8.6-to-4.9.0-upgrade.md).
