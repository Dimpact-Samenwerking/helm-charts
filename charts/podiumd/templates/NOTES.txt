{{- if .Values.frankgateway.networkPolicies.enabled }}

  NetworkPolicies are ENABLED. Inbound traffic to the inway is accepted only
  from namespace:

      {{ .Values.frankgateway.networkPolicies.ingressNamespace }}

  This must be the namespace of the pod that OPENS connections to the inway.
  For NGINX Gateway Fabric 2.x that is the per-Gateway DATA plane pod, which
  runs in the Gateway's own namespace — NOT the control plane's namespace,
  which is the one carrying the product name. Confirm it now:

      kubectl get pods -A | grep gateway-nginx

  If that pod is in a different namespace than the one above, inbound traffic
  is being dropped: silently, with no log line on either side, because the
  packet never arrives. It will look like a TLS or connectivity fault.
{{- end }}
